# EXORYN Typography Specification

## Primary display
**Space Grotesk** — SemiBold / Bold  
Use for headlines, product names, navigation emphasis and presentation titles.

## Technical accent
**IBM Plex Mono** — Medium  
Use selectively for IDs, event names, metrics, code-like labels and audit/evidence details.

## Body/UI
**Inter** — Regular / Medium / SemiBold  
Use for product UI, documentation, long-form content and commercial material.

## Wordmark
The supplied EXORYN wordmark is an outlined vector asset and must be used from the logo files.
Do not recreate it by typing the company name in a font.

## Rules
- Sentence case for product copy.
- ALL CAPS only for short technical labels.
- Avoid extended futuristic display fonts in body text.
- Numerical data should use tabular figures where available.
