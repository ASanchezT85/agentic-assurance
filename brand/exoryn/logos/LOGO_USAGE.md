# EXORYN Logo Usage

## Master
Use `exoryn-primary-horizontal.svg` for most corporate contexts.

## Dark background
Use `exoryn-primary-horizontal-dark.svg`.

## Icon
Use `exoryn-icon-primary.svg` for avatars, favicons and compact product surfaces.

## Monochrome
Use the monochrome files for legal, procurement, compliance and low-color environments.

## Clearspace
Minimum clearspace around the logo = the width of the central diamond/core in the icon.

## Minimum size
- Horizontal digital: 160 px wide.
- Icon digital: 24 px.
- Print horizontal: 35 mm wide.

## Never
- add glow to the master logo;
- make the X three-dimensional;
- rotate the icon;
- alter segment colors;
- add a shield, robot head or financial chart inside the mark;
- place it on visually noisy imagery without a solid field.
