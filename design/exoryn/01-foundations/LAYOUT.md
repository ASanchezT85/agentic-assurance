# Layout, Spacing and Density

## Base spacing
4, 8, 12, 16, 24, 32, 40, 48, 64 px.

## Web shell
- Sidebar: 232 px expanded; 72 px compact.
- Top bar: 64 px.
- Main max readable width: 1600 px; data surfaces may fill available viewport.
- Standard panel gap: 16 px.
- Page padding: 24 px at >= 1024; 16 px below.

## Grid
- 12-column desktop grid.
- 8-column tablet grid.
- 4-column mobile grid.

## Density
Default is “institutional dense”, not consumer spacious. Data tables target 40-44 px row height. Critical evidence/detail panels may use 48 px rows.

## Radius
- 6 px compact controls/badges.
- 12 px panels/cards.
- 20 px only for hero/product-marketing surfaces, not routine dense operator UI.
